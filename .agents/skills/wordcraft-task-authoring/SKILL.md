# WordCraft 任务创作标准规范与流水线 (Task Authoring Skill)

本 Skill 规范了为 **WordCraft（语块工坊）** 创建新学习任务的完整流程。所有任务均严格遵循针对 **4-6 年级阿斯伯格（ASD Level 1）儿童** 的特教认知设计准则。

---

## 🎯 核心特教认知准则 (Pedagogical Principles)

1. **结构高度可预测（3 问黄金律）**：
   - **Step 1（基础要素）**：固定 3 问（谁？在哪里？在做什么？），纯要素选择，不强制拼接；
   - **Step 2（修饰要素）**：固定 3 问（针对画面特征提出具体的修饰问题，涵盖神态/外貌、动作/工具细节、环境光影/额外特征）；
   - **Step 3（完整句子）**：展示汇集的 6 个语块素材盒，由学生自主编写完整通顺的句子；
   - **Step 4（纸上默写）**：大字版展示最终句子，由学生在纸面上默写，老师拍照存档。
2. **严禁啰嗦表达（高信息纯度）**：
   - 杜绝一切冗余套话、口号式鼓励和冗长背景介绍；
   - 提问直接、具体、一目了然，选项词块具有高辨识度与画面对应性。
3. **具象感官锚定（具象化 > 抽象化）**：
   - 优先引导观察可直接用肉眼确认的物理特征（色彩、光影、材质、手持道具、身体动作、微表情）；
   - 避免过于抽象、模糊的心智推测，将其具象化为行为或可观察神态。
4. **低感官过载（Low Sensory Overload）**：
   - 画面构图主体明确、焦点突出、色调柔和（莫兰迪/柔和大地/和煦晨光色调），避免高频杂乱视觉噪点。

## 🔥 3 级难度体系 (Difficulty Rating Scale)

每个任务必须明确标定其难度属性（`difficulty`: 1 | 2 | 3）：

| 难度等级 | 标识 | 适用对象与教学目标 | 语言修辞特征 | 典型示例 |
| :--- | :--- | :--- | :--- | :--- |
| **难度 1（基础起步）** | 🔥 | 刚开始接触句式扩写的学生；建立主谓宾骨架与最基础的色彩/动作认知。 | 基础定语与状语；直接客观的颜色、方位与简单动作。 | *红色的、大声地、在草地上、跑来跑去* |
| **难度 2（进阶拓展 · 默认）** | 🔥🔥 | 掌握基础句型，训练具体观察力与工具/环境修饰。 | 较丰富的动宾修饰、手持道具、光影色彩、微神态。 | *展开双翼太阳能帆板、幽蓝色的扫描光束、全神贯注地* |
| **难度 3（挑战跃升）** | 🔥🔥🔥 | 语言组织能力较强，训练比喻修辞、复合感官（声光触温）与多层次从句。 | 比喻拟人、多重状语、环境烘托、复合时间因果连接。 | *如轻盈伞盖般的荧光水母、伴着清晨和煦的微风、一边……一边……* |

## 🎨 主题与视觉风格多样性 (Theme & Visual Diversity)

任务主题不应局限于游戏，而应积极拓展至更广阔的儿童兴趣领域：

| 领域分类 | 典型场景示例 | 视觉风格推荐 | 重点训练词汇类型 |
| :--- | :--- | :--- | :--- |
| **🌿 自然生态与动物奇遇** | 晨光森林里的小松鼠、雨后荷塘的红蜻蜓、雪山上的小雪豹 | 暖色水彩绘本风 / 吉卜力清新风景 | 感官形容词（茸茸的、晶莹的）、动作动词（轻盈跃起、抖落） |
| **🚀 科学探索与天文航天** | 火星探测车采集岩样、射电望远镜观测星云、树屋实验室 | 干净 Low-poly / 细腻 3D 渲染 | 科技工具动词（调节镜头、扫描）、光影细节（幽蓝冷光、璀璨星环） |
| **🪵 生活手工与美食工坊** | 木匠爷爷打磨摇摇木马、烘焙小屋烘烤面包、陶艺旋转拉坯 | 暖光等轴测（Isometric）/ 黏土定格风 | 触觉材质词（温润厚实、香气四溢）、精细动作（细细打磨、小心塑形） |
| **🏰 温情奇幻与童话冒险** | 浮空灯塔守护人点亮星灯、森林树洞书屋的小精灵、蒸汽朋克飞艇 | 奇幻像素沙盒 / 温馨蒸汽朋克 | 想象力修饰词（漂浮微光、旋转发条）、环境光晕（斑驳金光） |
| **🏛️ 历史人文与考古探索** | 沙漠绿洲旁的古代集市、竹林深处的古琴台、地底水晶洞窟 | 复古手绘 / 电影质感概念原画 | 方位空间词（石阶尽头、檐角下）、状态描绘（宁静幽深、青苔斑驳） |

## 🔄 标准创作两阶段流水线 (Two-Phase Protocol)

创建新任务时，必须严格执行**“双阶段协同流程”**：

### 阶段 1：方案提案与难度确认 (Proposal Phase)

当用户提出生成需求时，**先不要直接生成图片和代码**，而是先构思并输出 **3 个各具特色的候选方案卡**，并标明推荐难度（默认 🔥🔥 2），同时询问用户确认：

```markdown
### 💡 任务设计候选提案

#### 方案 A：🌿《晨光森林里的采松果松鼠》（自然生态）
- **推荐难度**：🔥 1（基础）
- **画面构图**：清晨薄雾中，一只蓬松尾巴的小松鼠双手捧着硕大松果站在生满苔藓的树枝上，金色晨光穿透树叶。
- **Step 1 基础要素**：小松鼠 / 在晨光森林里 / 捧着松果
- **Step 2 修饰亮点**：毛茸茸的蓬松大尾巴 / 双手紧紧捧着油亮松果 / 金色晨光穿透斑驳树影

#### 方案 B：🚀《火星红岩上的探路小车》（科学天文）
- **推荐难度**：🔥🔥 2（进阶 · 默认）
...
#### 方案 C：🪵《阳光木坊里的摇摇小木马》（生活手工）
- **推荐难度**：🔥🔥🔥 3（挑战）
...

> 🧭 请告诉我您选择的方案（A / B / C）以及期望的难度等级（1 / 2 / 3，默认为 2）。
```

等待用户确认后再进入阶段 2。

---

### 阶段 2：全量资产生成与代码装配 (Assembly Phase)

用户确认方案与难度后，执行以下自动化装配步骤：

1. **生成 16:9 高清场景图**：
   - 使用 `generate_image` 工具生成 16:9 比例图片；
   - 提示词必须明确：主体突出、光线自然、无文字水印、色彩温和；
   - 将图片保存至 `public/scenarios/<task_id>.jpg`（同时支持复制一份到 artifact 供预览）。
2. **结构化数据编写（Strict TypeScript Schema）**：
   - 严格按照 `TaskItem` 接口结构组织 Step 1 ~ Step 4 的内容；
   - 填入对应 `difficulty`（1 | 2 | 3）；
   - 确保 Step 2 包含 3 个**与画面强关联的具体问题**（`questionTitle`），词块丰富度契合设定难度；
   - 提供符合小学 4-6 年级语文规范的 `sampleCompleteAnswer`。
3. **写入代码库**：
   - 更新 `src/data/tasks.ts`，将新任务添加到 `SENTENCE_TASKS` 数组；
   - 更新 `src/data/modules.ts` 中的 `totalTasks` 数量；
4. **编译验证**：
   - 运行 `npm run build` 验证 100% 编译通过，无类型错误。
5. **Git 询问**：
   - 遵从项目规则，向用户汇报改动概要并询问是否 commit/push。
