# 🎮 WordCraft（语块工坊）：面向阿斯伯格儿童的小学语文阶梯式写作 PWA

> 💡 **项目定位**：专为小学 4-6 年级阿斯伯格（Asperger's / ASD Level 1）儿童量身打造的渐进式、可视化语文写作辅助学习工具（Progressive Web App）。通过游戏视听素材激发兴趣，利用结构化、分级“语块”脚手架突破写作难关。

---

## 🌟 核心理念与背景

阿斯伯格综合征（高功能孤独症谱系）儿童通常具有独特的认知风格：
- **优势**：逻辑思维强、细节观察力敏锐、对特定兴趣领域（如游戏、机械、自然世界）有高度专注力。
- **挑战**：面对宏观抽象的情感表达、模糊的命题作文容易产生不知所措的焦虑感；在“心智理论”（视角转换、推测他人心理）、段落连贯性以及组织宏观篇章结构上需要更清晰、明确的规则与支架。

本项目旨在**将写作拆解为清晰的“积木构建系统”**，利用儿童热爱的游戏与具象视觉刺激作为锚点，提供可预测、低认知负荷、低感官过载的学习环境。

---

## 📐 核心 UI 与交互设计准则（Prompt 级规范）

1. **UI 文案极简原则（严禁啰嗦）**：
   - 杜绝冗长口水话、冗余解释或口号式鼓励。
   - 文案必须直接、具体、一目了然（如：“谁？”、“在哪里？”、“在做什么？”、“下一步”）。
   - 阿斯伯格儿童对信息过载极度敏感，界面需保持高信息纯度、低视觉杂讯。

2. **两大核心区域与分问题推进架构**：
   - **图片区域 (Image Area)**：清晰呈现视觉画面与 4 步任务进度。
   - **构建区域 (Construction Area)**：严格以**“具体问题”**为驱动分步推进：
     - **Step 1 问题**：谁？在哪里？在做什么？
     - **Step 2 问题**：他们是什么样的？动作与周围有什么细节？
     - **Step 3 问题**：怎样连成一句通顺完整的话？
     - **Step 4 行动**：在纸上默写这句话（老师拍照存档）。

---

## 🧩 4 步 To-Do 进阶进度条

```
[任务进度条]
  ├── ⬜/✅ 1. 基础要素（回答 3 个基础问题：谁？在哪里？在做什么？只选不拼句）
  ├── ⬜/✅ 2. 修饰要素（逐题问答补充细节：神态？动作方式？环境光影？）
  ├── ⬜/✅ 3. 完整句子（呈现已选语块素材盒，学生自主输入完整句子并支持朗读校对）
  └── ⬜/✅ 4. 纸上默写与拍照存档（在实体练习纸上工整书写，老师拍照确认存档）
```

---

### 1. 视听素材驱动（Visual & Interest-driven Stimuli）
- **多媒体刺激源**：精选游戏精彩截图、短小游戏动态片段（如《我的世界》建造、《塞尔达传说》探索、《动物森友会》生活场景等）及日常生活趣味视听。
- **明确视觉焦点**：避免画面杂乱，提供高关注点指引，引导学生聚焦关键人物、动作与环境。

### 2. 纸面书写与数智结合（Step 4 特色）
- 鼓励孩子在纸张上手写记录，锻炼手部精细动作协调能力。
- 老师/家长可直接使用 iPad 拍照上传存档，由 IndexedDB 本地持久化，生成专属成长档案。

### 3. 感官友好与 UI/UX 规范
- **低感官刺激配色（Sensory-Friendly Palette）**：采用温和、舒适的莫兰迪/柔和大地色系或低饱和度蓝绿色调，避免高频闪烁、荧光刺眼色彩。
- **高可预测性界面**：布局规整、按键反馈明确、无突兀弹窗或倒计时紧迫感。
- **正向非惩罚机制**：提供安全感，鼓励反复尝试与自由探索。

### 4. iPad 触控优先与 PWA 跨平台特性
- **iPad 触控深度适配**：针对 1024x768、1180x820、1366x1024 等主流 iPad 屏幕优化分栏与画板比例；所有按钮和语块方块触控区域 $\ge 48\text{px}$，手势平滑防误触。
- **全屏沉浸与离线就绪**：支持“添加到 iPad 主屏幕”，独立窗口全屏运行；集成 Service Worker 离线强缓存，无网络也可流畅训练。
- **Vercel 现代化托管**：配置自动化静态资源优化、SPA 路由支持与极速 CDN 加速。

## 🧭 Gemini 与创作者共同探索课题

我们将在后续开发与设计中深入探索以下三个核心领域：

### 1. 针对谱系特质的“精准题型设计”
- **词汇锚定题**：看视频选/填动作动词与感官形容词（视觉、听觉、触觉）。
- **句子拼装积木**：拖拽式句式扩展（何时 + 谁 + 在何地 + 怀着怎样的心情 + 做了什么）。
- **心理/情绪可视化卡片**：将抽象心理具象化为状态卡片或情绪仪表盘，辅助视角代入。
- **因果/逻辑连接器**：提供“因为...所以...”、“紧接着”、“出乎意料的是”等逻辑支架。
- **结构导图填空**：通过结构卡片串联起承转合。

### 2. 游戏与视听素材采集与标注规范
- **素材筛选标准**：画质清晰、动作连贯、情节积极无暴力、长度适中（3-15秒）。
- **结构化元数据标注**：
  - `场景标签`（森林、城堡、实验室...）
  - `动作要素`（跳跃、建造、寻找、避开...）
  - `情绪/氛围`（紧张、专注、欢快、静谧...）
  - `写作训练目标`（适合练动词 / 练环境 / 练逻辑）
- **素材库扩充流水线**：制定自动化/半自动化剪辑与标注方案。

### 3. 项目的持续演进与长远规划
- **扩展至更多语文维度**：阅读理解拆解、社交情境沟通对话、成语/修辞具象理解。
- **AI 辅助反馈（温柔陪伴者）**：引入温和的 AI 辅导角色，提供正面、具体的鼓励与点拨建议，而非冷冰冰的红笔打分。
- **家长与特教老师看板**：可视化学习进度与语言表达丰富度分析。

## 🛠️ 技术栈与部署规范

- **版本**：v0.1.0
- **应用形态**：PWA (Progressive Web App - iPad 优先)
- **部署平台**：Vercel (Edge CDN + SPA 静态路由加速)
- **前端架构**：Vite 6 + React 18 + TypeScript + TailwindCSS 3 (Morandi Low-Sensory Palette)
- **PWA 支持**：`vite-plugin-pwa` (Workbox 全量离线预缓存与 Service Worker)
- **状态与存储**：LocalStorage（本地安全持久化任务进度）
- **语音与音效**：Web Speech API (TTS 中文范句朗读) + Web Audio API (低刺激触觉反馈音效)
